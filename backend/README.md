# Pandu backend

FastAPI modular monolith: documents ingestion, hybrid retrieval (pgvector + FTS + RRF),
streaming chat with citations, evaluation, and a multi-provider AI seam.

See the repo-root `README.md` and `ARCHITECTURE_REVIEW.md` for the full story;
`docs/adr/` for decisions. Dev loop: `make dev` from the repo root.
